# Citybloom

An original 3D city-building game for the browser (TypeScript, Vite, Three.js, Preact).
Work in progress: see `PROGRESS.md` for the current state, `DESIGN.md` for the technical design and
`SPEC.md` for the brief.

```sh
npm install
npm run dev        # play at http://localhost:5173
npm test           # unit + scenario tests
npm run e2e        # end-to-end tests (Playwright)
```
